# Coffee Sales Dashboard
## Project Overview
This project focuses on analyzing coffee shop sales data and creating an interactive dashboard using Microsoft Excel. The goal was to transform raw sales data into meaningful insights that can help identify sales trends, customer preferences, and overall business performance.

The project demonstrates the use of Excel for data cleaning, analysis, visualization, and dashboard development.

The final dashboard provides an interactive overview of coffee shop sales performance. Users can filter the data to explore sales by different coffee types, locations, products, and time periods.

## Objectives
- Analyze coffee shop sales performance
- Identify trends in sales over time
- Determine the most popular coffee products
- Analyze sales by product category and coffee type
- Compare sales across different store locations
- Identify customer purchasing patterns
- Create an interactive dashboard to communicate key findings
- Data Analysis

The dataset contains coffee shop transaction information that was used to analyze sales performance across different products, locations, and time periods.

Key areas analyzed include:
- Total sales 
- Total orders
- Quantity sold
- Sales by coffee type
- Sales by product category
- Sales by store location
- Sales trends by month
- Sales trends by day and time

Excel Skills Used:
- Data Formatting
- Pivot Tables
- Pivot Charts
- XLOOKUP
- INDEX & MATCH
- IF Statements
- Data Visualization
- Slicers
- Interactive Dashboard Design
- Dashboard

## Key Insights
The analysis provides insight into:
- Which coffee products generate the most sales
- Which store locations perform the best
- How sales change over time
- Which products are most frequently purchased
- Differences in customer purchasing behavior
- Overall sales performance across the business
